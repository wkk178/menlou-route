# 门楼层记·故事里

西四北三条社区文商活化计划智慧导览系统

在线地址：https://wkk178.github.io/menlou-route/

## 1 项目概述

本项目面向北京西四北三条历史文化街区，建设一套胡同游览导览系统。系统依据游客的游览偏好、时长及同行情况，自动生成步行路线，并通过电子地图、3D 门楼档案和语音讲解，将沿线的门楼建筑、名人故居、开放院落与新型文商业态串联为一条完整的游览动线。

项目同时配套"石老娘议事厅"协调机制和"门楼公益金"反哺机制，将导览及业态收益用于社区老龄福利与门楼维护，形成可持续的社区微更新模式。

## 2 系统功能

系统由以下五个功能模块组成：

| 模块 | 功能说明 |
| --- | --- |
| 智能推荐 | 通过 5 项问卷（体验主题、游览时长、同行人员、兴趣标签、是否避开居民区）采集游客需求，生成个性化路线 |
| 数字导览 | 在电子地图上展示路线、点位编号、用时与步行距离，提供点位简介，并集成 AI 问答助手 |
| 3D 展厅 | 展示门楼三维模型，提供讲解音频、文化典故与居民口述记忆 |
| 我的路线 | 汇总路线时长、距离，给出文化深度、商业体验、居民友好度评分及逐站行程 |
| 项目介绍 | 说明项目背景、体验设计与社会价值 |

系统在后端对游客问卷数据进行记录，并据此对路线推荐权重做自适应调整，同时提供数据查询接口用于运营复盘。

## 3 业务设计

沿线共设 12 个点位，按"门楼里"三层体验划分：

| 体验层 | 内容 | 点位 |
| --- | --- | --- |
| 读门 | 门楼形制识别与砖雕纹样解读 | 隆长寺旧址、11 号广亮大门、13 号金柱大门、44 号金柱大门 |
| 推门 | 名人故居与开放院落参观 | 程砚秋故居、傅增湘故居、45 号居民院落 |
| 创门 | 新型业态体验与文化消费 | 无问西东精酿、京剧体验馆、拾光茶铺、故事书店、胡同夜市 |

## 4 目录结构

```
menlou-route
├── index.html            首页
├── quiz.html             智能推荐（问卷）
├── map.html              数字导览（地图、AI 问答）
├── gate-3d.html          3D 展厅
├── route.html            我的路线
├── about.html            项目介绍
├── original-index.html   首页旧版本（留存）
├── app.py                后端服务
├── config.json           推荐权重配置
├── user_data.json        问卷与路线历史记录
├── requirements.txt      后端依赖清单
├── demo.glb              门楼 3D 模型
├── n3.mp3                讲解音频
├── bg-hero.jpg           首页背景图
└── hello.txt             测试文件
```

各文件说明如下：

| 文件 | 说明 |
| --- | --- |
| index.html | 系统首页，展示项目主题及三大体验入口，并连接各功能页面 |
| quiz.html | 问卷页面，采集游客偏好并提交至后端，获取路线后跳转地图页 |
| map.html | 地图导览页面，加载并绘制路线，展示点位信息，嵌入 AI 问答组件 |
| gate-3d.html | 3D 展厅页面，按点位编号加载对应的模型说明、音频与文字档案 |
| route.html | 路线详情页面，展示路线评分与逐站行程 |
| about.html | 项目介绍页面 |
| original-index.html | 首页的早期版本，仅作留存，不参与当前页面跳转 |
| app.py | 后端服务程序，包含点位数据、路线生成、问卷记录与权重更新功能 |
| config.json | 路线推荐所用的主题、标签、人群权重，由后端读取并自动更新 |
| user_data.json | 游客问卷及生成路线的历史记录，由后端自动写入 |
| requirements.txt | 后端运行所需的 Python 依赖 |
| demo.glb | 3D 展厅使用的门楼模型文件 |
| n3.mp3 | 3D 展厅使用的讲解音频 |
| bg-hero.jpg | 首页背景图片 |
| hello.txt | 测试文件 |

## 5 说明

后端服务未启动时，前端自动采用内置示例数据生成路线，各页面可正常演示。
