

# 西四云境·门里乾坤

西四北三条社区文化数字交互与智能导览平台

在线地址：https://wkk178.github.io/menlou-route/

## 1 项目概述

本项目面向北京西四北三条历史文化街区，建设一套基于 Serverless 架构的轻量级、跨端响应式数字导览系统。系统依托原生前端技术与底层核心算法，自动生成步行路线，并通过电子地图、4D 时空卷轴、3D 门楼档案、AI 伴游和 NFC 电子护照，将沿线的门楼建筑、名人故居、开放院落与新型文商业态串联为一条完整的游览动线。

项目同时配套线下实地打卡与核销机制，实现线上数字空间与线下物理空间的 O2O 文商转化闭环，将导览及业态收益用于社区老龄福利与门楼维护，形成可持续的社区微更新模式。

## 2 系统功能

系统由以下六个核心功能模块组成：

| 模块 | 功能说明 |
| --- | --- |
| 4D 时空卷轴 | 在首页通过 IntersectionObserver 侦听滚动事件，利用视差动画与 SVG 锚点，展示各历史纪元的建筑更迭轨迹 |
| 智能导览地图 | 基于 Leaflet.js 构建，采用双线性插值算法实现 1:1 像素级校准，结合 Dijkstra 算法生成单向防折返导览路径 |
| 3D 展厅 | 展示广亮大门、金柱大门等六种门楼三维模型，提供文化典故与讲解音频 |
| NFC 电子护照 | 结合线下 NFC 碰一碰与扫码打卡，通过底层 LocalStorage 状态机完成集章判定，动态生成专属漫游证书 |
| AI 问答助手 | 全局悬浮的“老街坊”智能体，接入 Coze Web SDK 提供自然语言理解与历史故事生成任务 |


## 3 业务设计

沿线共精准落位 23 个点位，按三层体验划分：

| 体验层 | 内容 | 点位 |
| --- | --- | --- |
| 读门·寻古 | 门楼形制识别与砖雕纹样解读 | 隆长寺山门、11号广亮大门、15-19号金柱大门、31号如意门、41号蛮子门、西洋门、麒麟图门墩等 12 处古迹点位 |
| 推门·阅巷 | 名人故居与胡同邻里生活记忆 | 程砚秋故居（如意门）、傅增湘藏书楼（藏园）、三条西口随墙门等 3 处活态文化院落 |
| 创门·共生 | 社区新型业态体验与商业核销 | 叙杯、无名蹄花、黑潮酿造、大宇宙、紫光园、蝗虫精酿、易应茶舍、无问西东精酿等 8 处新消费空间 |
